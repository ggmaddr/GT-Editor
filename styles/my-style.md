# My Editing Style

> **Status: BASELINE — not yet learned.** No reference videos analysed yet. Every value below is an

## Identity (original — never copied from references)
- Energetic, clean, high-contrast talking-head shorts. Bold uppercase captions, one accent colour.
- Principles are extracted from references; footage, music, logos, fonts-as-branding, and signature
  graphics of other creators are never reused.

## Structure & story
| Principle | Baseline value | Evidence |
|---|---|---|
| Hook | spoken hook in the first 1–2 s + on-screen hook title (≤7 words) for 2.4 s | default |
| First word | ≤ 0.3 s after frame 0 (no dead intro) | default |
| Arc | hook → problem → payoff/steps → CTA | default |
| Length | 25–60 s | default |

## Pacing
| Principle | Baseline | Evidence |
|---|---|---|
| Max pause kept | 220 ms (`pacing.maxPauseMs`) | default |
| Word padding | 70 ms before / 140 ms after | default |
| Dramatic hold after ? ! … | 320 ms | default |
| Target shot length | ~3.5 s, punch-in alternation on every cut | default |

## Camera & motion
- Punch-in 1.14× on alternating shots; hook shot 1.08× with slow 3% push-in.
- Accent transition (whip + whoosh) only at topic/clip changes; otherwise hard cuts.

## Captions & typography
- Montserrat 800, uppercase, 84 px, 12 px black stroke, ≤3 words/page, centre at 66 % height.
- Active word = accent `#FFD23F` scaled 1.1×; numbers/stats = `#4FE3C1`.
- Titles: Anton, 118 px, at 20 % height. All text inside safe zone (top 230, bottom 440, right 170 px).

## Colour
- Footage ungraded (natural). Graphics palette: white / near-black panels / yellow accent / mint secondary.

## Sound
- Dialogue −16 LUFS per clip → master −14 LUFS integrated, true peak ≤ −1 dBTP.
- Music bed (user-licensed only) 0.14 → ducked to 0.05 under speech. SFX kit is self-synthesised.
